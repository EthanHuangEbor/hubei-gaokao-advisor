# GitHub Skill Hunter

Use this skill to inspect candidate GitHub skills before project adoption.

Checklist:

- Record repo, skill name, URL, license, stars, last updated, intended use.
- Mark commercial suitability only when the license is explicit and commercial-friendly.
- Review SKILL.md, README, scripts, install steps, network behavior, and destructive commands.
- Adopt by install only when license is clear and scripts are safe for the project.
- Use learn-only when license is unclear or behavior is too broad.
- Reject any skill that impersonates real public figures for Doctor.Peak.
